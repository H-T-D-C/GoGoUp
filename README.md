# GoGoUp

Minecraft Java Edition 26.1.2用のサーバー専用Fabric Modです。オーバーワールド・ネザー・エンドの建築空間をY=2031まで広げ、設置できる最大Y座標を設定ファイルやコマンドで変更できます。クライアントへのGoGoUp導入は不要です。

地形の生成範囲とネザーの岩盤屋根は維持し、上方に建築空間を追加します。既存ワールドにも適用する設計です。検証状況は[動作確認記録](docs/validation.md)を参照してください。

## 導入

1. Java 25、Minecraft 26.1.2対応のFabric LoaderとFabric APIをサーバーに導入します。開発時のバージョンは `gradle.properties` にあります。
2. サーバーを停止し、ワールドをバックアップします。
3. `build/libs/gogoup-1.0-beta.jar` をサーバーの `mods/` に配置します。`-sources.jar` は導入用ではありません。更新時は古いGoGoUp JARを置き換えてください。
4. サーバーを起動します。

## 設定

初回起動時に `config/gogoup.json` を作成します。

```json
{
  "maxBuildY": 2031
}
```

`maxBuildY` は設置できる最大Y座標を含みます。`300` ならY=300まで許可し、Y=301以上を拒否します。設定範囲は0〜2031の整数で、16の倍数などの制限はありません。ファイルを編集した場合は `/gogoup reload` で反映します。

起動時に設定が不正なら理由を表示して起動を停止します。稼働中の保存・再読込に失敗した場合は、現在の上限を維持します。

## コマンド

権限レベル2以上の管理者とサーバーコンソールで使用できます。コンソールでは先頭の `/` を省略します。

| コマンド | 動作 |
| --- | --- |
| `/gogoup`、`/gogoup status`、`/gogoup height` | 現在の上限と設定範囲を表示 |
| `/gogoup height 300` | 全3ディメンションの上限をY=300へ即時変更し、JSONへ保存 |
| `/gogoup reload` | 設定ファイルを検証して再読込 |

変更に再起動・再接続は不要です。

## 適用範囲と制約

- ブロックアイテムによる設置、プレイヤーのバケツによる液体設置、`/setblock`、`/fill` を制限します。`/fill` は範囲の一部でも上限を超えると全体を拒否します。
- 上限を下げても既存のブロックは削除しません。上限を戻すと再び設置できます。
- ピストン、ディスペンサー、流体の自然な流れ、`/clone` などは設定上限による制御の対象外です。
- 内部のディメンション領域はY=2031まで固定で確保します。上限を下げてもチャンクの内部サイズは縮小しません。
- 同じディメンション定義を上書きするデータパックとは競合する可能性があります。Modを外す前には拡張領域の建築を含むバックアップを確保してください。

## 開発

JDK 25と同梱のGradle Wrapper（9.8.1）を使用します。

```powershell
.\gradlew.bat build
.\gradlew.bat clean build
.\gradlew.bat runServer
```

`build` はJARを作成し、`clean build` は生成物を削除して再作成します。`runServer` は `run/` に開発用サーバーを起動します。ワールドを読み込むには、そのサーバーのEULAへの同意が必要です。macOS/Linuxでは `./gradlew` を使用します。

自動テストは未導入です。ソース構成と貢献手順は[AGENTS.md](AGENTS.md)、設計・残作業は[PLAN.md](PLAN.md)を参照してください。ローカルログの共有用 `test/`、開発ワールドの `run/`、キャッシュ・ビルド生成物はGit管理対象外です。
